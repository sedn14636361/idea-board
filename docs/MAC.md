# Macで使う

IdeaBoard は Mac でもそのまま動きます。用途に応じて2通りあります。

## 方法A: Macアプリとして起動する（おすすめ）

Mac に **Node.js（LTS版）**（https://nodejs.org/）を入れておきます。

1. プロジェクトフォルダの中の `dev` フォルダを Finder で開き、そのフォルダを右クリック →「フォルダに新規ターミナル」
   （出てこない場合は、ターミナルを開いて `cd ` と入力してからフォルダをドラッグ＆ドロップ）
2. 初回のみ:

       npm install

3. 起動:

       npm run start

ウィンドウがアプリとして開きます。⌘C / ⌘V / ⌘Q などのショートカットもそのまま使えます。

## 方法B: .app（dmg）を作って、次からアイコンで起動する

Mac 上で、`dev` フォルダで:

    npm run dist:mac

`dev/release` フォルダに **IdeaBoard-1.0.0-arm64.dmg**（Apple Silicon）などができます。
dmg を開いて `IdeaBoard.app` を「アプリケーション」フォルダにドラッグすれば、以後はアイコンから起動できます。

### 「開発元を確認できません」「悪質なソフトウェアかどうか確認できません」と出たら

**ウイルスが見つかったわけではありません。** macOS は、Appleに登録された開発者の署名（年99ドルの有料登録が必要）が付いていないアプリすべてに、この警告を出します。自分でビルドしたアプリなので必ず出ます。

開き方は次のとおりです。上から順に試してください。

**1. 右クリックで開く（多くの場合これで解決）**

`IdeaBoard.app` を **右クリック（control+クリック）→「開く」** → 出てきたダイアログで「**開く**」。
初回だけこの手順が必要で、2回目からは普通にダブルクリックで起動します。

**2. システム設定から許可する**

「ゴミ箱に入れますか？」と出て 1 が使えない場合:

1. いったん「キャンセル」を押す（**ゴミ箱に入れない**）
2. アップルメニュー →「システム設定」→「プライバシーとセキュリティ」
3. 下の方に「"IdeaBoard" は開発元を確認できないため……」という表示が出るので「**このまま開く**」を押す

**3. ターミナルで隔離マークを外す**

1 も 2 も効かない場合（macOS 15 以降で特に多い）、インターネット経由で受け取ったファイルに付く「隔離マーク」を外します。
ターミナルを開いて次を実行してください。

    xattr -dr com.apple.quarantine /Applications/IdeaBoard.app

（アプリを別の場所に置いている場合はそのパスに変えてください。`xattr -dr com.apple.quarantine ` と入力してから、アプリをターミナルにドラッグ＆ドロップすると確実です）

この操作は「このアプリは自分がビルドしたものだと分かっているので、ダウンロード由来の制限を外す」という意味です。自分で作ったものだと分かっている場合にだけ実行してください。

## 起動が遅いとき

次の3つが主な原因です。上から順に確認してください。

### 1. 起動のたびにビルドしている（いちばん多い原因）

`npm run start` は、**毎回アプリを組み立て直してから**起動します。
すでに組み立て済みなら、次のコマンドで**すぐ起動**できます。

    npm run app

コードを変更したときだけ `npm run start`（または `npm run build`）を使ってください。

### 2. Intel向けのアプリをApple Siliconで動かしている

`npm run dist:mac` では、次の2種類のdmgができます。

- `IdeaBoard-x.x.x-arm64.dmg` … **M1/M2/M3 などのMac用**
- `IdeaBoard-x.x.x.dmg` … Intel Mac用

Apple SiliconのMacで**Intel用のほうを入れると、変換しながら動くため非常に遅くなります。**
「このMacについて」でチップを確認し、Appleシリコン（M1以降）なら **arm64** と付いたほうを使ってください。

確認方法: アプリを右クリック →「情報を見る」→「種類」が
「アプリケーション（Intel）」なら入れ直しが必要です。

### 3. 毎回セキュリティの検査が走っている

インターネット経由で受け取ったアプリには目印が付いており、起動のたびに検査されることがあります。
次のコマンドでその目印を外せます。

    xattr -dr com.apple.quarantine /Applications/IdeaBoard.app

自分でビルドしたものだと分かっている場合にだけ実行してください。

### 警告を完全に無くすには

Apple Developer Program（年99ドル）に登録し、証明書でアプリに署名して Apple に公証（notarization）を申請する必要があります。自分と身近な人が使うだけなら、上の手順で開くほうが現実的です。

### そもそもビルドせずに使う

警告が煩わしい場合、ビルドせずターミナルから起動する方法もあります（`dev` フォルダで）。この場合 Gatekeeper の警告は出ません。

    npm run start

※ Windows用のexeはWindows上で、Mac用のdmgはMac上でしか作れません（`npm run dist:win` / `npm run dist:mac`）。

## 方法C: ブラウザで使う

公開しているアドレス（https://sedn14636361.github.io/idea-board/）を開くか、`dev` フォルダで:

    npm run dev

表示される `http://localhost:5173/` を Safari や Chrome で開くだけでも使えます。
Chrome なら アドレスバー右の「インストール」からアプリとして登録もできます。

## データについて

- 保存先は Mac 内（`~/Library/Application Support/IdeaBoard`）です
- **WindowsやiPadとは別々に保存されます**。移したいときは 📁メニュー →「ファイルへ保存」でJSONを書き出し、移行先で「ファイルを開く」で読み込みます
