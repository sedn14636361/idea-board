# クラウド同期の設定

設定すると、次のことができるようになります。

- スマホで書いたものが、**外出先からでもパソコンに届く**
- 別のパソコンと**同じボードを共有**できる（付箋の位置もそのまま）

Googleの無料サービス（Firebase）を使います。費用はかかりません。

---

## アプリの案内どおりに進めるのが簡単です

IdeaBoard を開き、「**デバイス接続**」→「**かんたん設定をはじめる**」を押してください。
画面の案内に従って進めるだけで設定できます。

- Firebaseの画面は、アプリ内のボタンから**その画面を直接**開けます（メニューをたどる必要がありません）
- 貼り付けが必要な内容も、ボタン1つでコピーできます
- 最後に「つないでみる」を押すと、**どこでつまずいているかをアプリが教えてくれます**

以下は、その手順を文章にまとめたものです。困ったときの確認に使ってください。

> Firebaseの画面は時々作り替えられます。ボタンの名前が少し違っていても、
> 同じ意味のものを探せば進められます（例:「プロジェクトを作成」と「プロジェクトを追加」）。

---

## 手順

### 1. 置き場所を作る

1. https://console.firebase.google.com を開き、Googleアカウントでログイン
2. 「プロジェクトを作成」→ 名前は何でもよい（例: `ideaboard`）
3. Googleアナリティクスは「無効」でかまいません

### 2. データベースを作る

`https://console.firebase.google.com/project/（プロジェクトID）/firestore` を開くと直接たどり着けます。
メニューから探す場合は、左の「**Database と Storage**」を開き、NoSQL のところにある「**Firestore**」です。
**Realtime Database とは別のもの**なので注意してください。

1. 「**データベースを作成**」を押す
2. 場所（ロケーション）はそのままでよい
3. ルールの種類を聞かれたら「**本番環境モード**」を選ぶ（次の手順で設定し直すので、テストモードでも進められます）
4. 「作成」

### 3. 使ってよいことを設定する

Firestoreの画面の上にある「**ルール**」タブを開き、**中身をすべて消してから**次を貼り付けて「公開」。
（直接開く場合は `.../firestore/rules`）

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /inbox/{room}/items/{item} {
      allow read, write: if request.auth != null;
    }
    match /projects/{room}/items/{item} {
      allow read, write: if request.auth != null;
    }
  }
}
```

### 4. ログインを許可する

`.../authentication/providers` を開きます（メニューでは「Authentication」）。

1. 初めての場合は「**始める**」を押す
2. 「**ログイン方法**」（Sign-in method）の一覧から「**匿名**」を選ぶ
3. 「**有効にする**」にして保存

### 5. アプリにつなぐ

`.../settings/general`（左上の歯車 →「プロジェクトの設定」→「全般」）で次の2つを確認します。

**プロジェクトID**
画面の上のほう、「プロジェクト名」のすぐ下にあります（例: `idea-board-c8568`）。

**ウェブAPIキー**
同じ画面を**下までスクロール**して「マイアプリ」へ。

- ウェブアプリがある場合 … それを選ぶと出る「SDK の設定と構成」の中の `apiKey` の値
- まだ無い場合 … 「**アプリの追加**」→「**&lt;/&gt;**」（ウェブ）を選び、ニックネームを入れて登録すると表示されます（Hostingのチェックは不要）

これをアプリの手順5に入れて「つないでみる」を押してください。
**合言葉**は自動で作られます（他人に見つけられないための文字列です）。

---

## 他の端末にも同じ設定を入れる

1. 設定できたパソコンで「デバイス接続」→「**設定をコピー**」
2. もう一方のパソコンで「デバイス接続」→「**他の端末の設定を貼り付ける**」
3. スマホの場合は ⚙ →「設定を貼り付け」

同じ設定が入っていれば、同じ置き場所を共有します。

---

## 使い方

**スマホから**
書いた時点で自動的にパソコンへ送られます。電波が無いときは端末に残り、つながったときに送られます。
パソコン側は「デバイス接続」に件数が出るので、押して貼り付けます。

**保存先はサーバー**
設定すると、すべてのプロジェクトがサーバーに保存されます。どの端末で開いても同じ内容になります。
編集すると数秒後に自動で送られます。新しい端末で開くと、サーバーにある最新のプロジェクトがそのまま出ます。

電波が無いあいだはその端末に控えておき、つながったときに送ります。オフラインでも使えます。

プロジェクトごとに「デバイス接続」→「サーバーに置かない」を選ぶと、そのプロジェクトはこの端末だけに置かれます。

**2つの端末で同時に編集したとき**
あとから送ろうとした端末に「両方で変更されています」と出ます。
「サーバーの方」か「この端末の方」を選んでください。黙って上書きされることはありません。
選ばなかった方は、その端末の 📁メニュー →「復元ポイント」に残るので、あとから取り戻せます。
端末の空き容量が足りず控えを残せないときは、置き換えを止めて画面上部で知らせます。
そのときは「ファイルへ保存」で書き出してから、不要なプロジェクトや画像を減らしてもう一度選んでください。

**画像**
画像の多いプロジェクトも、分けて保存するので画像ごと残ります。

## うまくいかないとき

アプリの「つないでみる」を押すと、原因に応じた案内が出ます。

| 出るメッセージ | 直しかた |
|---|---|
| APIキーが違うようです | 手順5でAPIキーを取り直す |
| 匿名ログインが有効になっていません | 手順4をやり直す |
| ルールが設定されていません | 手順3のルールを貼り直す |
| データの置き場所が見つかりません | 手順2をやり直す、またはプロジェクトIDを確認 |

## よくある質問

**お金はかかりますか**
かかりません。無料枠（1日5万回の読み書き）に対し、この使い方では1日数十回程度です。

**他人に見られませんか**
「合言葉」を知らない限り、どこにデータがあるか分かりません。自動で作られる文字列は推測できない長さです。

**やめたいとき**
「デバイス接続」→「解除」。Firebaseのプロジェクトを削除すれば、預けたデータも完全に消えます。
