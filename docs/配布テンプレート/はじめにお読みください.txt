========================================
 IdeaBoard （アイデアボード）
========================================

アイデアを付箋として貼り、線でつなぎ、まとまりを作りながら
考えを整理するための道具です。

物語の構成、企画のたたき台、調べ物の整理などに使えます。


----------------------------------------
 はじめかた
----------------------------------------

【Windows をお使いの場合】

  「IdeaBoard.exe」をダブルクリックしてください。
  インストールは必要ありません。

  ▼「WindowsによってPCが保護されました」と出たときは
     「詳細情報」→「実行」で開けます。
     個人が作ったアプリのため出る表示で、問題はありません。


【Mac をお使いの場合】

  「IdeaBoard.app」を右クリック（control を押しながらクリック）して
  「開く」を選び、もう一度「開く」を押してください。

  最初の1回だけこの手順が必要です。次からは普通に開けます。

  ▼「壊れているため開けません」と出たときは
     ターミナルで次を実行してください。

     xattr -dr com.apple.quarantine （アプリをここにドラッグ）

  ▼ Mac用が2種類ある場合
     M1・M2・M3 などのMacをお使いなら「arm64」と付いたほうを、
     それ以前のMac（Intel）なら付いていないほうをお使いください。
     間違えると、動きますが非常に遅くなります。


----------------------------------------
 使い方
----------------------------------------

  アプリの上のほうにある「使い方」ボタンを押すと、
  操作の一覧がいつでも見られます。

  ・付箋を貼る … 「＋ 追加」→「付箋」
                  （何もない場所をダブルクリックでも貼れます）
  ・動かす     … 付箋の上のほうをドラッグ
  ・つなぐ     … 🔗 を押して、つなぎたい相手をクリック
  ・探す       … 左上の ☰ で一覧が開きます

  書いたものは自動で保存されます。保存ボタンはありません。


----------------------------------------
 大事なことがら
----------------------------------------

  ● データはこのパソコンの中に保存されます
      Windows … %APPDATA%\IdeaBoard
      Mac     … ~/Library/Application Support/IdeaBoard

    アプリのファイルを移動したり入れ替えたりしても、
    中身は消えません。

  ● 控えの取りかた
    大事なものは、左上の 📁 →「ファイルへ保存」で
    書き出しておくと安心です。
    別のパソコンへ移すときも、このファイルを使います。

  ● スマホや別のパソコンと つなぎたいとき
    「デバイス接続」→「かんたん設定をはじめる」から、
    画面の案内どおりに進めれば設定できます（無料・任意）。
