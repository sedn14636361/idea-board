# 他の人に配るとき

受け取った人が「解凍して起動するだけ」で使えるようにまとめます。

---

## いちばん手軽: HTML 1枚で渡す

    npm run single

`release/IdeaBoard.html` ができます（約300KB）。これを1つ渡すだけです。
受け取った人はダブルクリックで開けば、インストールなしで使えます。
どの機種の上で作っても、Windows / Mac のどちらでも動きます。

更新するときも、新しい `IdeaBoard.html` で上書きしてもらうだけです。
中身はブラウザ側（またはサーバー）に保存されているので、ファイルを置き換えても消えません。

ただし、次の機能は exe / dmg 版だけです。

- 同期フォルダ（OneDrive など）を使ったパソコン同士の共有
  （クラウド同期を設定すれば、HTML 版でもサーバー経由で共有できます）

---

## 1. アプリを作る（exe / dmg で渡す場合）

配る相手のパソコンに合わせて、その機種の上で作ります。
（Windows用はWindowsで、Mac用はMacで作る必要があります）

    npm install      （初回のみ）
    npm run dist:win     Windows用
    npm run dist:mac     Mac用

`release` フォルダに、次のものができます。

| 機種 | ファイル |
|---|---|
| Windows | `IdeaBoard x.x.x.exe`（そのまま起動できる形式） |
| Mac（M1以降） | `IdeaBoard-x.x.x-arm64.dmg` |
| Mac（Intel） | `IdeaBoard-x.x.x.dmg` |

---

## 2. 配るものをまとめる

新しいフォルダを作り、次の2つを入れてzipにします。

```
IdeaBoard/
├── IdeaBoard.exe               （またはdmg）
└── はじめにお読みください.txt    ← 配布テンプレート からコピー
```

`配布テンプレート/はじめにお読みください.txt` は、
受け取った人向けに書いてあります。そのまま同梱してください。

**Mac用を配るときは、arm64版とIntel版のどちらかを選んで入れてください。**
相手の機種が分からない場合は両方入れ、説明文の該当箇所を残しておきます。

---

## 3. 渡す

- 少人数に1回だけ … Google ドライブや OneDrive にアップしてリンクを共有
- 更新しながら配る … GitHub の Releases が便利です（履歴が残り、リンクが変わりません）

ファイルは数十MB〜100MB台になります。

---

## 伝えておくとよいこと

受け取った人が戸惑いやすいのは次の2点です。同梱の説明文にも書いてありますが、
渡すときに一言添えると親切です。

1. **起動時に警告が出ること**
   個人が作ったアプリのため、WindowsでもMacでも警告が出ます。
   説明文のとおりに進めれば開けます。

2. **使い方はアプリの中にあること**
   上部の「使い方」ボタンから見られます。

---

## 更新版を配るとき

1. `package.json` の `version` と `src/version.js` の `APP_VERSION` を上げる
2. `CHANGELOG.md` に変更点を1行書く
3. もう一度 `npm run dist:win` / `dist:mac`
4. 新しいファイルを配る

**受け取った人のデータは消えません。**アプリを入れ替えても、
書いた内容はパソコンの中に残ったままです。
