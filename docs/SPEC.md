## 機能一覧

| 分類 | 機能 |
|---|---|
| 付箋 | 追加（色・タイトル・タグを決めて貼るモードあり） / 削除 / ドラッグ移動 / リサイズ / 色変更（6色） / テキスト入力 / 複製 / 他ボード・他プロジェクトへのコピー / 範囲選択による複数選択・一括操作 |
| 入れ子 | 付箋の中にボードを格納（3段階まで）。展開・収納の切替 |
| 接続 | 付箋同士を直線で接続 / 線にメモを書ける / 線のクリックで編集・削除 / 親子間は接続不可 |
| ID・引用 | 自動採番ID（#番号） / 検索して他の付箋を引用 / 引用先へジャンプ |
| タグ | 付箋へのタグ付与 / プリセットタグ（カテゴリ別） / タグ一覧 / タグによる強調表示 / 付箋上の表示数制限（+nに格納） |
| ボード | 複数ボードをタブで管理 / タイトル編集 / ボード直書きの文字 / 背景色の領域（カテゴリ分け） / 手書き（Apple Pencil対応） / 画像の貼り付け |
| プロジェクト | 複数プロジェクトの保持・切替・新規開始 / JSONファイル書き出し・読み込み |
| 表示 | ズーム（30〜200%・ピンチ対応） / 自由配置・グリッド配置 / 付箋・シンプル枠の見た目切替 |
| 動作環境 | デスクトップアプリ（Windows exe / Mac dmg） / iPad・ブラウザ向けPWA |
| 保存 | 全操作を自動保存（0.8秒デバウンス） |

## 画面構成

### ツールバー（上段）

| 項目 | 説明 |
|---|---|
| ☰ | 付箋リスト（サイドパネル）の開閉 |
| 📁 プロジェクト名 ▾ | プロジェクトメニューを開く（名前変更・一覧・切替・新規・削除・ファイル保存/読込） |
| ＋ 付箋を貼る | 表示中の画面中央付近に付箋を追加 |
| ＋ 文字 | ボードに直接書ける文字（ラベル）を追加 |
| ＋ 領域 | 押した後にボード上をドラッグすると、その範囲に背景色の領域を作成 |
| 設定して貼る | ONにすると、付箋を貼る前に色・タイトル・タグを決めるパネルが出る |
| ＋ 画像 | 画像ファイルを選んでボードに貼る |
| ✏️ 手書き | 手書きモードに入る（下部にペンのツールバーが出る） |
| 自由配置 / グリッド配置 | 配置モードの切替 |
| − / % / ＋ | ズーム操作。%クリックで100%に戻る |
| 付箋 / シンプル | 付箋の見た目切替 |
| ▨ 選択 | 押した後に範囲をドラッグして複数選択（タッチ操作用。マウスは常時ドラッグで選択可） |
| 🏷 タグ一覧 | 現在のボードのタグ一覧パネルを開く |
| ⚙ 設定 | 設定画面を開く（グリッド間隔・キャンバスサイズ・タグ表示数・文字サイズ・プリセットタグ） |
| このボードを空にする | 現在のボードの付箋・線・文字を全削除（確認あり） |

### ボードタブ（中段）

- タブのクリックでボード切替。アクティブなタブはタイトルを直接編集可
- タブ横の ✕ でボード削除（確認あり）。右端の ＋ で新規ボード追加

### ボード（作業領域）

- 3200 × 2200 px のキャンバスをスクロール・ズームして使用
- 空きスペースをダブルクリックで付箋追加

## 仕様詳細

### 付箋（ノード）

- 新しい付箋は**常に灰色**で貼られる（ランダムではない）。色を変えなければ灰色のまま
- 付箋を貼ると**設定パネルが開き、色・タグ・タイトルを決めてから**貼れる（既定でON）。ツールバーの「設定して貼る」をOFFにすると、パネルを出さず即座に貼られる
- タイトルは**「タイトルを付ける」チェックを入れたときだけ**付箋に欄が出る。後から付箋の操作列の「**T**」ボタンで切り替えることもできる
- 各付箋は左上に **#番号**（ボード内で自動採番、欠番は再利用しない）
- **タイトル**: 本文の上に1行のタイトル欄がある。未入力の場合は**本文の最初の1行**が自動的に見出しとして使われる
  - この見出しは、俯瞰表示・引用プレビュー・引用の検索リスト・タグ一覧など、付箋を一覧する全ての場所で使われる
- 最上段の操作列: 色ボタン（パレットが開く） / ▸▾ 入れ子の開閉 / ⧉ 複製・コピー / 🔗 接続 / ✕ 削除
- **複製・コピー（⧉）**: 入れ子の中身・タグ・内部の線ごと複製する
  - このボードに複製: 元の位置から少しずらして配置。他の付箋への引用も維持
  - 他のボード / 他のプロジェクトへコピー: 移動先のルートに配置され、#番号は移動先で振り直し。サブツリー外への引用は外れる。他プロジェクトへのコピー先は、そのプロジェクトで選択中のボード
  - 操作列の**ボタン以外の余白がドラッグのつかみ代**（付箋モードでは上部の色帯も可）
- 右下の三角ハンドルをドラッグでリサイズ。**収納時と展開時のサイズは別々に記憶**
- 削除すると中に格納された子孫の付箋・関連する線・引用参照もすべて削除
- 未記入時のプレースホルダーは「アイデアを書く」

### 付箋リスト（サイドパネル）

- ツールバー左端の **☰** で開閉する。**ボードの左側に並んで表示される**ので、リストを見ながらボードを操作できる
- **検索**: タイトル・本文・タグ・#番号のいずれでも絞り込める
- **タグ絞り込み**: 使われているタグがボタンで並び、押すとそのタグの付箋だけに絞られる
- **「このボード」/「全ボード」** を切り替えると、プロジェクト内の全ボードを横断して探せる
- 各行には #番号・見出し・タグが並び、入れ子の中にあるものは「#5 の中」、他ボードのものは「📄 ボード名」と表示される
- 行をクリックするとその付箋へジャンプ（**収納されていれば自動展開**、別ボードなら**そのボードに切り替えてから**移動してハイライト）

### 複数選択

- ボードの空きスペースを**マウスでドラッグすると範囲選択**でき、矩形に触れた最上位の付箋と**ボード直書きの文字**がまとめて選択される（青枠表示）
- **Shift+クリック**で付箋を個別に選択へ追加/除外
- 選択中の付箋をつかむと**まとめて移動**できる（グリッド吸着も有効）
- 画面下部の操作バーから: ⧉ 一括複製 / ✕ 一括削除（確認あり） / 解除
- 空きスペースのクリック、選択外の付箋の操作、ボード切替で選択は解除される
- タッチ操作は通常スクロールが優先されるため、範囲選択は「▨ 選択」モードを使う（マウスはいつでもドラッグで選択可）

### 入れ子（付箋の中のボード）

- ▸ ボタンで付箋内にミニボードを展開。ミニボード内のダブルクリックまたは右下の ＋ で子付箋を追加
- 深さは **3段階まで**（親 → 子 → 孫）。3段目の付箋には展開ボタンが表示されない
- 収納中は ▸ の横に格納数を表示（例: ▸3）
- 親をドラッグ・削除すると中身も一緒に移動・削除
- 子付箋を展開しても親のボードからはみ出さないよう自動で収まる

### 接続（線）

- 🔗 を押した後、つなぎたい相手の付箋をクリックで接続。もう一度 🔗 で解除
- 線は**付箋の枠と枠を結ぶ直線**（たわみなし）。文字の上を通らないよう枠の外周に接続
- 線のどこをクリックしてもメモ編集のポップアップが開く（当たり判定は太め）。「完了」で閉じ、「線を外す」で削除
- **線のメモ**: 入力したメモは線の中央に白いラベルで表示され、関係性（「〜の原因」「対比」など）を書き添えられる。ラベルをクリックすると再編集できる
- **同一ペア間の重複接続は不可**。**親子（格納関係）の付箋同士は接続不可**（何段離れていても）
- 収納中の付箋への線は、**見えている親に束ねてオレンジの点線**で表示
- 展開中は**子→別親を直接**赤い実線で結ぶ（親を経由する中継はしない）
- 同じ親の中の付箋同士は見えているノード間を直接つなぐ

### ID・引用

- 引用方法は2通り:
  1. 付箋下部の「❝引用」→ 検索（タグ・本文・番号のいずれでもヒット）→ リストから選択
  2. 本文に `#番号` と直接書く（この場合は本文編集で解除）
- 引用すると付箋下部に**引用先付箋のトップ**（色帯・#番号・本文冒頭）をミニチュア表示
  - 引用先が入れ子の中にある場合は「#親番号内」と格納場所を併記
  - クリックで引用先へジャンプ。**収納中でも祖先を自動展開**し、ハイライトして知らせる
  - ❝引用由来のものは ✕ で解除可能
- 自分自身の引用・重複引用は不可。表示は最大6件

### タグ

- 付箋下部の「＋タグ」からポップアップで追加・削除（Enterでも追加）
- **プリセットタグ**: ポップアップ下部にカテゴリ別の候補が表示され、1タップで付与できる（既定カテゴリ: シーン / 設定 / アイデア / その他）。内容は設定画面で自由に編集可能
- **タグの色分け**: タグは属するカテゴリの色で表示される（既定: シーン=青、設定=紫、アイデア=橙、その他=緑。自由タグはグレー）。チップ・強調枠・タグ一覧・引用ピッカーのすべてに色が反映され、カテゴリ色は設定画面のカラーピッカーで変更できる
- **赤色強調タグ**: 重要・緊急を示すタグ（既定: 重要度高・優先度高・未・未実装）はカテゴリ色より優先して**赤**で表示される。対象タグは設定画面で編集可能
- 赤色強調タグは付箋上で**常に先頭に表示**され、表示数制限（+n格納）の対象にならない
- **付箋上の表示数制限**: 付箋には設定した件数（既定3件）までタグを表示し、超過分は「+n」チップに格納。タップで全表示、「«」で再び格納（レイアウトが崩れないため）
- 付箋上のタグチップをクリックすると、**同タグの付箋を緑枠で強調・それ以外を減光**。ツールバーの「タグ: ◯◯ ✕」または再クリックで解除
- 「🏷 タグ一覧」パネル: ボード内の全タグを使用数つきで一覧 → タグ選択でそのタグを含む付箋一覧 → 付箋クリックでジャンプ。「強調」ボタンで強調表示の切替も可能

### ボード直書きの文字

- 「＋ 文字」で追加。枠のないテキストとしてボードに配置（見出し・ラベル用）
- ホバーで操作UIが出現: ⠿ ドラッグ移動 / A1〜A3 文字サイズ3段階（15/22/34px） / ✕ 削除
- グリッド配置・ズームに追従。ボードごとに保存

### 領域（背景色オブジェクト）

- 「＋ 領域」を押してからボード上をドラッグすると、その範囲に**半透明の色付き領域**が作られる（付箋の下に敷かれる）
- 領域の上でも付箋の追加・移動・範囲選択は通常通り行える（領域は操作を妨げない）
- 操作は左上の名前バーから: ⠿ ドラッグで移動 / 領域名の入力 / ● 色変更（5色） / ✕ 削除（**上の付箋は消えない**）。右下のハンドルでリサイズ
- **領域を移動すると、その上に乗っているアイテム（付箋・文字）も相対位置を保ったまま一緒に移動する**（付箋は中心が領域内にあるものが対象）
- グリッド配置・ズームに追従し、ボードごとに保存される
- 「済んだもの」「検討中」などのエリアを色で分けておくと、付箋を置くだけで視覚的にカテゴリ分けできる

### 画像

- 追加方法は3通り: ツールバーの「＋ 画像」/ **Ctrl+V（⌘V）で貼り付け** / **ボードへドラッグ＆ドロップ**（複数同時可）
- 画像にマウスを乗せると操作UIが出る: ドラッグで移動 / 右下のハンドルで**縦横比を保ったままリサイズ** / 右上の ✕ で削除（タッチ端末では常に表示）
- 表示位置は領域の上・付箋の下。付箋を画像の上に重ねて注釈を付けられる
- 保存容量を抑えるため、取り込み時に**長辺1400pxへ自動縮小**される（`IMAGE_MAX_PX`で変更可）
- 画像を多く入れると保存容量の上限に達することがある。その場合は警告が出るので、📁メニューの「ファイルへ保存」でバックアップを取る

### 手書き

- ツールバーの「✏️ 手書き」で手書きモードに入り、ボード上に直接描ける。付箋や領域の上をまたいで自由に線を引ける
- **Apple Pencilの筆圧に対応**（強く書くと太く、軽く書くと細くなる）
- 下部のツールバーで操作: 色5種 / 太さ3段階 / 消しゴム / ↩︎ 直前の線を取り消す / 全消し / 「完了」でモード終了
- **消しゴムは2モード**（消しゴムを選ぶと切替ボタンが出る）
  - **部分**: なぞった箇所だけを消す（線は分割されて残る）
  - **線ごと**: 触れた線をまるごと消す（オブジェクト単位）
- **指＋ペン / ペンのみ** の切替あり。「ペンのみ」にすると指ではスクロールだけになり、手のひらや指が触れても描かれない
- 手書きは付箋の上のレイヤーに描かれ、ボードごとに保存される。ツールバーの「✏️ 表示中／非表示」でレイヤーごと隠せる
- 手書きモード中は付箋の操作が一時的に止まる（描画に専念できる）。付箋を動かしたいときは「完了」でモードを抜ける

### 配置モード

- **自由配置**: 任意の位置に配置（背景はドット）
- **グリッド配置**: 26px間隔の方眼に移動・リサイズが吸着。**切替時に既存の付箋も一括で整列**
- モードはミニボード内にも適用。設定は保存される

### ズーム

- 範囲 30%〜200%。ツールバーの −/＋、**Ctrl（⌘）+ マウスホイール**（カーソル位置中心）、iPadでは**2本指のピンチ**
- **俯瞰表示**: 一定倍率（既定65%）より縮小すると、各付箋が自動的に「**見出し＋タグ**」の表示に切り替わる
  - 見出しは付箋のタイトル（未設定なら本文の最初の1行）。**付箋の枠からはみ出す横長のラベル**として表示されるので、小さく縮小しても読みやすい（文字サイズは縮小率に関わらず一定）
  - タグは**その付箋が何なのかを示すものを優先**して最大3件＋残数。既定では「シーン」「設定」カテゴリのタグ（起・承・キャラクター・世界観など）が優先され、進捗や重要度（済/未・優先度）は入りきらなければ省略される
  - どのカテゴリを優先するかは、設定画面のカテゴリ行にある「**俯瞰で優先**」ボタンで切り替えられる
  - 入れ子がある付箋には格納数（▸3）も表示される。それ以外の細かいUIは隠れてすっきりする
  - 切り替わる倍率は設定画面の「見出し表示に切替わる倍率」で変更できる
- ドラッグ・リサイズ・ダブルクリック・線の描画はすべて倍率補正済み。倍率は保存される

### 見た目切替

- **付箋**: 色付きの紙＋上部の色帯＋濃い影
- **シンプル**: 白地に色付き細枠の四角（上辺4pxで色の意味は維持）＋軽い影
- 機能は両モードで同一。選択は保存される

### プロジェクト

- プロジェクト = ボード一式（ボード・付箋・線・タグ・引用・文字・採番状態）を含む最上位の単位
- 📁 メニューから: 名前変更 / 一覧からの切替 / ＋ 新規プロジェクト開始 / ✕ 削除（確認あり）
- **ファイルへ保存**: 現在のプロジェクトをJSONとして書き出し（バックアップ・別PCへの移行用）
- **ファイルを開く**: JSONを新しいプロジェクトとして読み込み
- 切替時も全プロジェクトが保持されるため、作業内容が失われることはない

### 確認ダイアログ

- 破壊的操作（ボードを空にする / ボード削除 / プロジェクト削除）は必ずアプリ内ダイアログで確認
- 設定画面と付箋の設定パネルは、**枠外をクリックすると閉じる**（確認ダイアログは誤操作防止のため枠外クリックでは閉じない）
- ブラウザ標準の `confirm` / `alert` / `prompt` は使用しない（実行環境によりブロックされるため）

## データの保存

### 起動時のプロジェクト選択

- プロジェクトが複数ある状態でアプリを起動すると、**開くプロジェクトを選ぶ画面**が表示される
- 各プロジェクトのボード数・付箋の枚数が並び、前回開いていたものには印が付く
- 「＋ 新しいプロジェクト」で新規に始めることも、「ファイルから開く」でJSONを読み込むこともできる
- 📁メニューの「プロジェクト選択画面を開く」から、いつでも呼び出せる

### 復元ポイント（自動バックアップ）

- 編集を続けると、**10分おきに自動で復元ポイント**が作られ、最新6件まで保持される
- 📁メニューの「復元ポイント」に日時が一覧されるので、選ぶとその時点の状態に戻せる
- 「今の状態を残す」ボタンでいつでも手動の復元ポイントを作れる
- **復元する直前の状態も自動で「復元前」として残る**ので、戻しすぎてもやり直せる
- 保存容量に収まらない場合は、古い復元ポイントから自動的に削除される

### 自動保存

- すべての編集は**0.8秒のデバウンス後に自動保存**（保存操作は不要）
- 保存は**プロジェクトごとに別々**に行われ、内容が変わったプロジェクトだけが書き込まれる（他のプロジェクトに影響しない）
- 保存先: Electronの `localStorage`（キー: `idea-board-state`）
  - Windowsでの実体は `%APPDATA%\IdeaBoard` 配下
  - ポータブルexeでもこの場所を使うため、**exeの移動・差し替え・再ビルドでデータは消えない**
  - データを完全に消すには上記フォルダを削除

### 保存データ構造

保存キーは次の3種類に分かれています。

- `idea-board-index` … プロジェクト一覧と共通設定（表示倍率・グリッド・設定画面の内容など）
- `idea-board-project:<id>` … プロジェクト本体（ボード・付箋・画像・手書きなど）
- `idea-board-backups:<id>` … そのプロジェクトの復元ポイント

プロジェクト本体の構造:

```json
{
  "projects": [
    {
      "id": "...", "name": "プロジェクト名",
      "currentBoardId": "...",
      "boards": [
        {
          "id": "...", "title": "ボード名", "nextNum": 5,
          "notes": [
            {
              "id": "...", "num": 1, "parentId": null,
              "x": 0, "y": 0, "w": 190, "h": 170, "ew": 430, "eh": 400,
              "text": "...", "color": 0, "tags": ["..."], "refs": ["noteId"],
              "expanded": false, "z": 12
            }
          ],
          "edges": [{ "id": "...", "from": "noteId", "to": "noteId" }],
          "texts": [{ "id": "...", "x": 0, "y": 0, "text": "...", "size": 1, "z": 3 }]
        }
      ]
    }
  ],
  "currentProjectId": "...",
  "gridMode": false, "zoom": 1, "simpleStyle": false, "zMax": 42,
  "settings": {
    "grid": 26, "canvasW": 3200, "canvasH": 2200,
    "noteTagLimit": 3, "textSizes": [15, 22, 34],
    "alertTags": ["重要度高", "優先度高", "未", "未実装"],
    "presetTags": [{ "name": "シーン", "color": "#4A78B0", "tags": ["起", "承", "..."] }]
  }

```

- 旧形式（プロジェクトなし・ボードなし時代）のデータは読み込み時に自動移行される

### ファイル書き出し

- 📁 →「ファイルへ保存」で現在のプロジェクト単体をJSONとしてダウンロード
- 「ファイルを開く」で読み込むと**新しいプロジェクトとして追加**される（上書きしない）

## セットアップとビルド

### 必要なもの

- Node.js（LTS版）: https://nodejs.org/

### 初回セットアップ

```
npm install
```

### 起動

```
npm run start        # デスクトップアプリとして起動
npm run dev          # ブラウザで動作確認（http://localhost:5173）
```

### iPadやブラウザで使う（PWA）

`npm run build` で生成される `dist` フォルダをWebに公開し、iPadのSafariで開いて「ホーム画面に追加」すると、全画面のアプリとして起動できます（オフライン動作対応）。詳しい手順は **IPAD.md** を参照。

### exeの作成（Windows）

```
npm run dist:win
```

- `release/IdeaBoard 1.0.0.exe`（ポータブル版）が生成される
- インストール不要。exe 1ファイルの配布でそのまま動く
- 初回はElectron本体のダウンロードのため数分かかる

### Macで使う / dmgの作成

Macでも `npm run start` でそのままアプリとして起動できます。アイコンから起動したい場合は Mac 上で:

```
npm run dist:mac
```

`release` に dmg が生成されます。未署名のため初回は右クリック →「開く」で起動してください。詳しい手順は **MAC.md** を参照。

※ Windows用exeはWindows上、Mac用dmgはMac上でのみビルドできます。

## カスタマイズ

### 設定画面（アプリ内・⚙ボタン）

以下はアプリ内の設定画面から変更でき、保存されます:

| 項目 | 既定値 | 意味 |
|---|---|---|
| グリッド間隔 | 26px | 背景の目盛りと吸着の両方に使用 |
| キャンバス幅 / 高さ | 3200 / 2200px | 作業領域の広さ |
| 付箋に表示するタグ数 | 3件 | 超過分は +n チップに格納 |
| 見出し表示に切替わる倍率 | 65% | この倍率より縮小すると付箋が見出し＋タグ表示になる |
| 文字のサイズ3段階 | 15, 22, 34px | ボード直書き文字のサイズ |
| プリセットタグ | 4カテゴリ | カテゴリの追加・削除・名前変更・色変更・俯瞰で優先の切替、タグの編集（「、」区切り） |
| 赤色で強調するタグ | 重要度高・優先度高・未・未実装 | カテゴリ色より優先して赤表示するタグのリスト |

「既定に戻す」で初期値に一括リセットできます。数値・タグの編集は欄の外をクリックした時点で確定します。

### コード側の定数（`src/IdeaBoard.jsx` 冒頭）

| 定数 | 既定値 | 意味 |
|---|---|---|
| `COLORS` | 6色 | 付箋の色パレット（名前・本体色・縁色）。末尾が新規付箋の既定色 |
| `MAX_DEPTH` | 2 | 入れ子の最大深さ（0,1,2 = 3段階） |
| `DEFAULT_SETTINGS` | - | 設定画面の各既定値（プリセットタグ含む） |

そのほか:

- ウィンドウ初期サイズ: `electron/main.cjs` の `width` / `height`
- アプリ名: `package.json` の `productName`（データ保存フォルダ名にも使われる点に注意）

### 実装上の注意（既知の落とし穴）

- **ドラッグのつかみ代**: 操作列の行自体に `data-nodrag` を付けないこと。付けるとシンプル枠モードでつかむ場所が消える。除外は操作ボタン・ポップオーバー個別に付与する
- **線の端点**: 付箋の実測矩形（ズーム補正済み）から枠の外周交点を計算している。ミニボード内の付箋も実測ベースなので、レイアウト変更時も座標計算の修正は原則不要
- **ブラウザダイアログ禁止**: `confirm` 等はサンドボックス環境でブロックされる。自前の `confirmBox` を使う
- 詳細な開発経緯は `CLAUDE.md` を参照
