# iPadで使う（PWA）

IdeaBoard はブラウザ版をそのままホーム画面アプリとして使えます。Mac も App Store 審査も不要です。

## 方法A: 同じWi-Fiのパソコンから開く（お試し・すぐ使える）

1. パソコン側でプロジェクトフォルダを開き、ターミナルで:

       npm install     （初回のみ）
       npm run dev

2. 表示される `Network: http://192.168.x.x:5173/` のURLをiPadのSafariで開く
3. 共有ボタン（□に↑）→「ホーム画面に追加」

※ この方法はパソコンを起動している間だけ使えます。常用するなら方法Bへ。

## 方法B: Webに置いて、いつでも使えるようにする（推奨）

1. パソコンでビルド:

       npm run build

2. できた `dist` フォルダの中身をWebに公開する。無料でできる例:
   - **Netlify Drop**: https://app.netlify.com/drop に `dist` フォルダをドラッグするだけ
   - **Vercel** / **Cloudflare Pages** / **GitHub Pages** でも可
3. 発行されたURLをiPadのSafariで開く
4. 共有ボタン →「**ホーム画面に追加**」

これで:

- アイコンから**全画面アプリ**として起動（Safariのバーが出ない）
- **オフラインでも起動**できる（Service Workerがアプリ本体をキャッシュ）
- データはiPad内に保存され、**閉じても次回そのまま復元**される

## iPadでの操作

| 操作 | 方法 |
|---|---|
| 拡大縮小 | 2本指のピンチ、またはツールバーの −/＋ |
| スクロール | 1本指のドラッグ（ボードの空きスペース） |
| 付箋の移動 | 付箋の上部（ボタン以外の余白）をドラッグ |
| 範囲選択 | ツールバーの「▨ 選択」を押してから範囲をドラッグ |
| 領域の作成 | 「＋ 領域」を押してから範囲をドラッグ |
| 文字の操作UI | タッチ端末では常に表示されます |
| 手書き | ツールバーの「✏️ 手書き」→ Apple Pencilで描く（筆圧対応） |
| 画像の追加 | 「＋ 画像」から写真ライブラリやカメラを選択 |

## 注意点

- データはブラウザ内（Safari）に保存されます。**iPadとパソコンのデータは別々**です。移したいときは 📁メニュー →「ファイルへ保存」でJSONを書き出し、移行先で「ファイルを開く」
- Safariのサイトデータを削除するとボードも消えます。大事なプロジェクトは定期的にJSONで書き出しておくと安心です
- 公開URLは誰でも開けます（データは各自の端末内なので他人に中身は見えませんが、気になる場合はNetlifyのパスワード保護などを使ってください）

## Apple Pencilで手書きする

1. ツールバーの「✏️ 手書き」をタップ
2. 下部のツールバーで色・太さを選び、そのまま描く（筆圧で線の太さが変わります）
3. 手のひらが当たって描かれてしまう場合は、下部ツールバーの「**指＋ペン**」をタップして「**ペンのみ**」に切り替える（指はスクロール専用になります）
4. 消したいときは「消しゴム」でなぞる。直前の線だけ消すなら「↩︎」
5. 「完了」で手書きモードを抜けると、付箋の操作に戻ります

手書きはボードごとに保存され、上部の「✏️ 表示中／非表示」でいつでも隠せます。
