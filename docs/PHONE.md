# スマホアプリ（受信箱）

思いついたことをその場で書き留めて、あとでパソコンのボードに貼るためのアプリです。
**ホーム画面のアイコンから開けて、電波が無くても使えます。**

---

## 1. スマホに入れる（初回だけ）

いちばん簡単なのは、公開しているアドレスを開く方法です。

1. スマホの Safari（Chrome）で https://sedn14636361.github.io/idea-board/mobile.html を開く
2. 共有ボタン（□に↑）→「**ホーム画面に追加**」

これで完了です。新しい版は自動で届きます。

### 自分で組み立てて置く場合

プロジェクトフォルダの中の `dev` フォルダで次を実行して、アプリのファイルを作ります。

    npm install     （初回のみ）
    npm run build

`dev/dist` フォルダができるので、これをWebに置きます。無料で一番簡単なのは **Netlify Drop** です。

1. パソコンのブラウザで https://app.netlify.com/drop を開く
2. `dev/dist` フォルダをドラッグ＆ドロップ（アカウント登録は不要）
3. `https://○○○.netlify.app` のようなアドレスが発行される

次にスマホで:

4. Safari（Chrome）でそのアドレスの末尾に **`/mobile.html`** を付けて開く
5. 共有ボタン（□に↑）→「**ホーム画面に追加**」

これで完了です。以後はアイコンをタップするだけで起動します。

---

## 2. 使い方

アプリ右上の **i** ボタンを押すと、使い方がいつでも見られます。

1. 「書く」タブで文章を入力し、色・タグ・まとめ先を選ぶ
2. 「**＋ 受信箱に入れる**」で保存（電波が無くても大丈夫です）
3. 「ためた分」タブに、書いたものが上から順に並びます

- **↑↓** で順番を入れ替えられます。この順番のままパソコンに取り込まれます
- 左のチェックで**選んだものだけ**を送る・書き出す・消すことができます
- 「まとめ先」を選んでおくと、パソコンで**その名前の囲み**が作られ、中に付箋が並びます

---

## 3. パソコンへ渡す

### 方法A: クラウド同期（おすすめ・どこからでも届く）

設定すると、**書いた時点で自動的にパソコンへ送られます。**
同じWi-Fiにいる必要も、パソコンが起動している必要もありません。

準備のしかたは [CLOUD.md](CLOUD.md) を参照してください。

※ **ホーム画面のアイコンから開いた場合は、この機能は使えません**（設定を覚えておけないため）。
その場合は方法Bを使ってください。

### 方法B: 書き出して渡す

- 「**共有・コピー**」… 文章としてメモアプリやメールに送れます
- 「**CSVで出力**」… 表計算ソフトで開ける形にします

パソコン側では「デバイス接続」→「貼り付けて取り込む」で読み込めます。

## よくある質問

**パソコンがオフでも書ける？**
書けます。スマホの中に残り、あとでまとめて渡せます。

**タグを増やしたい**
「タグを編集」から自由に足せます。増やしたタグは、パソコンに取り込むときに自動で追加されます。

**受信箱を空にしてしまった**
戻せません。送る前に消さないよう気をつけてください。

**アプリを更新したい**
公開しているアドレスから入れた場合は、何もしなくても新しい版が届きます。
自分で置いた場合は、`dev` フォルダで `npm run build` し直し、新しい `dev/dist` をNetlifyに再度ドラッグします。
スマホ側はアプリを開き直せば新しい版になります（書いたものは残ります）。
