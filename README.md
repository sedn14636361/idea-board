# IdeaBoard

版 6.2.0

アイデアを付箋として貼り、線でつなぎ、まとまりを作りながら考えるためのアプリです。
物語の構成、企画のたたき台、調べ物の整理などに使えます。

- Windows / Mac のアプリとして動きます
- iPad やブラウザでも使えます
- スマホで思いついたことを書き留め、あとでパソコンに取り込めます
- 作ったものは自動で保存され、次に開いたときそのまま続けられます

---

## できること

**付箋**
文字を書いて貼る。ドラッグで動かす、角を引っぱって大きさを変える、色を変える。
タイトルを付けると、縮小したときに見出しとして表示されます。

**つなぐ**
付箋どうしを線で結べます。線には「〜の原因」「対比」などのメモを添えられます。

**入れ子**
付箋の中に別の付箋を入れられます（3段階まで）。細かい要素をしまっておけます。

**まとまりを作る**
背景色の「領域」で囲んで区分けできます。領域を動かすと中身も一緒に動きます。

**タグ**
付箋にタグを付けて分類できます。「シーン」「設定」などのカテゴリごとに色分けされ、
重要なものは赤で目立ちます。タグから付箋を探すこともできます。

**そのほか**
手書き（Apple Pencilの筆圧対応）、画像の貼り付け、ボードに直接書く文字、
拡大縮小、複数のボード、複数のプロジェクト、テキストでの書き出し。

## 使い始める

### すぐ使う（インストール不要）

- **ブラウザで開く**: https://sedn14636361.github.io/idea-board/ （スマホ版は https://sedn14636361.github.io/idea-board/mobile.html ）
- **HTMLファイルで使う**: このページの「Code」→「Download ZIP」で保存して展開し、中の `IdeaBoard.html` をダブルクリック

どちらも、書いた内容はその端末のブラウザに保存されます（ブラウザで開いた版とHTMLファイルの版は、保存場所が別です）。
端末をまたいで使うときは、下の「スマホや他のパソコンと連携したいとき」を設定してください。

### アプリとして使う

[Node.js](https://nodejs.org/)（LTS版）を入れてから、zipを解凍したフォルダの中の **`dev` フォルダ**で次を実行します。

```
npm install     （初回のみ）
npm run start   組み立ててから起動する（コードを変えたとき）
npm run app     すぐ起動する（2回目以降はこちらが速いです）
```

一番上の `IdeaBoard.html` を作り直すときは次を実行します（どの機種の上でも作れます）。

```
npm run single      HTML 1枚で動く版を作り直す
```

exeファイルを作るときは、その機種の上で実行してください。

```
npm run dist:win    Windows用のexeを作る
npm run dist:mac    Mac用のdmgを作る
```

## スマホや他のパソコンと連携したいとき（任意）

アプリ単体でも使えますが、設定すると次のことができます。

- スマホで書いたものが、外出先からでもパソコンに届く
- 別のパソコンと同じボードを共有できる

「**デバイス接続**」→「**かんたん設定をはじめる**」を押すと、**画面の案内どおりに進めるだけで設定できます**。
無料のGoogleアカウントがあれば、費用はかかりません。詳しくは [docs/CLOUD.md](docs/CLOUD.md) を参照してください。

アプリ上部の「**使い方**」ボタンからも、操作の一覧をいつでも見られます。

## 基本の使い方

| やりたいこと | 操作 |
|---|---|
| 付箋を貼る | 「＋ 追加」→「付箋」、または空いている場所をダブルクリック |
| 動かす | 付箋の上の余白をドラッグ |
| 大きさを変える | 右下の角をドラッグ |
| 付箋をつなぐ | 🔗 を押してから、つなぎたい相手をクリック |
| 中に付箋を入れる | ▸ を押して開き、中でダブルクリック |
| まとめて選ぶ | 何もない場所をドラッグで囲む |
| 拡大縮小 | ツールバーの −／＋、Ctrl＋ホイール、iPadは2本指 |
| 探す | ☰ を押すと一覧が開きます（検索・タグで絞り込み） |
| 文章を取り出す | 「書き出す」からコピーまたはファイル保存 |

縮小していくと、付箋が自動的に「見出し＋タグ」の表示に切り替わり、
全体を見渡しやすくなります。

## 保存とバックアップ

書いた内容は**自動で保存**されます。保存ボタンはありません。

- 編集を続けると10分おきに「**復元ポイント**」が作られ、📁メニューから前の状態に戻せます
- 大事なものは 📁メニュー →「**ファイルへ保存**」でJSONとして書き出しておくと安心です
- 別のパソコンへ移すときも、このファイルを「ファイルを開く」で読み込みます

保存場所は、Windowsは `%APPDATA%\IdeaBoard`、Macは `~/Library/Application Support/IdeaBoard` です。
アプリを置き換えても内容は消えません。

## 困ったときは

**画面が真っ白になる**
エラーの内容が画面に表示されます。多くは古いデータが原因なので、
表示される「保存内容を初期化して再読み込み」で直ります（先にJSONを書き出しておくと安全です）。

**動作が重い**
画像を多く貼ると重くなります。使わないボードやプロジェクトを整理するか、
画像を減らしてみてください。

**保存できないと出る**
保存できる量の上限に達しています。📁メニューからファイルへ書き出し、
不要なプロジェクトを削除してください。

## 作り直したいとき（開発者向け）

作業はすべて `dev` フォルダの中で行います。

```
npm run check      書き間違いがないか確認する
npm run dev        ブラウザで開発版を動かす
npm run build      配布用のファイルを作る
npm test           保存・同期の仕組みを確かめる
npm run test:e2e   実ブラウザで確かめる（Chromium が必要）
```

- `dev/src/IdeaBoard.jsx` … アプリ本体
- `dev/src/MobileQuickAdd.jsx` … スマホ版
- `dev/electron/` … デスクトップアプリの土台
- `dev/tests/` … 試験
- `dev/CLAUDE.md` … 設計の経緯と、触るときの注意点
